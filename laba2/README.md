# Лабораторная работа №2: Классификация изображений и анализ робастности нейросети

## Описание проекта
В данной лабораторной работе реализована сверточная нейронная сеть (CNN) на PyTorch для классификации 3 классов геометрических изображений (Круг, Квадрат, Треугольник) размером 32x32 пикселя с исследованием:
1. Обучения на сбалансированной выборке (по 3000 картинок каждого класса = 9000 изображений).
2. Влияния дисбаланса классов (уменьшение одного класса до 100–300 картинок).
3. Устойчивости к искажениям (случайные цвета фона и фигур, повороты на любой угол 0–360°, аддитивный шум, битые пиксели).
4. Оценки качества для каждого класса в отдельности (Precision, Recall, F1-Score, Confusion Matrix).
5. Визуальной проверки случайного рисунка непосредственно в терминале (ASCII-арт) с выводом уверенности по классам.
6. Распараллеливания вычислений на ядра CPU (настройка числа ядер, бенчмарк 1 ядро vs N ядер для генерации данных и обучения сети).

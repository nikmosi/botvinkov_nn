# Лабораторная работа №2: Классификация изображений с помощью простого перцептрона (MLP)

## Описание
В данной лабораторной работе реализован многослойный перцептрон (MLP) с нуля — по архитектуре и формулам первой лабораторной работы ([../laba1/my.py](file:///home/nik/git-repos/botvinkoy/laba1/my.py)) — для классификации 3 классов геометрических изображений (Круг, Квадрат, Треугольник) размером 32×32 пикселя (3072 входа).

### Возможности и этапы:
1. **Генерация выборки**: 3 класса одинакового размера по 3 000 изображений (всего 9 000 шт.).
2. **Простой перцептрон**: архитектура `[3072, 64, 3]`, сигмоидальная функция активации, аналитический расчет производных и обратное распространение ошибки (Backpropagation) вручную по градиентам батча.
3. **Исследование дисбаланса**: уменьшение одного из классов до минимума (100–300 картинок) и оценка качества.
4. **Анализ робастности (искажения)**: устойчивость к шумам Гаусса, случайным поворотам (0–360°), битым пикселям (salt-and-pepper) и произвольным цветам фона/фигур.
5. **Поклассовая оценка**: расчет `Precision`, `Recall`, `F1-Score` и матрицы ошибок (Confusion Matrix) для каждого класса.
6. **Визуализация в терминале**: проверка случайного рисунка с отрисовкой в ASCII-арт и выводом вероятностей классов.
7. **Распараллеливание на ядра CPU**: настройка числа ядер/потоков в меню и бенчмарк ускорения (1 ядро vs N ядер).

## Быстрый запуск

```bash
# Установка окружения через uv
uv sync

# Интерактивное меню
uv run python main.py

# Полная автоматическая проверка всех этапов (режим сдачи)
uv run python main.py --auto

# Запуск тестов
uv run python test_laba2.py
```

## Пункты интерактивного меню

```text
1. Сгенерировать датасет (3 класса, размер 32x32)
2. Обучить перцептрон на текущем датасете
3. Автоматическая проверка на тестовой выборке (метрики по классам)
4. Проверить случайный рисунок (ASCII-визуализация в консоли)
5. Уменьшить количество одного класса (дисбаланс: 100-300)
6. Переключить искажения (шум, повороты, битые пиксели, цвета)
7. Настройка распараллеливания на ядра CPU (выбор ядер + бенчмарк)
8. Полный авто-тест всех этапов задания (режим демонстрации)
9. Сохранить / Загрузить веса перцептрона (model.json)
0. Выход
```

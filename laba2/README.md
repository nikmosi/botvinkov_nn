# Лабораторная работа №2: Классификация изображений с помощью простого перцептрона (MLP)

## Описание
В данной лабораторной работе реализован многослойный перцептрон (MLP) с нуля — по архитектуре и формулам первой лабораторной работы ([../laba1/my.py](file:///home/nik/git-repos/botvinkoy/laba1/my.py)) — для классификации 3 классов геометрических изображений (Круг, Квадрат, Треугольник) увеличенного размера **128×128 пикселей** (49 152 входа), чтобы обучение занимало **~1 минуту**.

### Возможности и этапы:
1. **Генерация выборки**: 3 класса одинакового размера по 3 000 изображений (всего 9 000 шт. размера 128×128 RGB).
2. **Простой перцептрон**: архитектура `[49152, 256, 3]` (49 152 входа $\to$ 256 скрытых нейронов $\to$ 3 выхода), сигмоидальная функция активации, аналитический расчет производных и обратное распространение ошибки (Backpropagation) вручную по батчам (размер батча 32, время обучения ~1 минута).
3. **Исследование дисбаланса**: уменьшение одного из классов до минимума (100–300 картинок) и оценка качества.
4. **Анализ робастности (искажения)**: устойчивость к шумам Гаусса, случайным поворотам (0–360°), битым пикселям (salt-and-pepper) и произвольным цветам фона/фигур.
5. **Поклассовая оценка**: расчет `Precision`, `Recall`, `F1-Score` и матрицы ошибок (Confusion Matrix) для каждого класса.
6. **Визуализация в терминале**: проверка случайного рисунка с отрисовкой в ASCII-арт и выводом вероятностей классов.
7. **Распараллеливание на ядра CPU**: настройка числа ядер/потоков в меню и бенчмарк ускорения (1 ядро vs N ядер).

## Быстрый запуск

```bash
# Установка окружения через uv
uv sync

# Запуск веб-интерфейса в браузере (порт 8088 по умолчанию)
uv run python web.py
# или: uv run python main.py --web

# Доступ через SSH Port Forward:
# на своем ПК: ssh -L 8088:localhost:8088 user@host
# в браузере:  http://localhost:8088

# Интерактивное консольное меню
uv run python main.py

# Распознавание собственной картинки по пути
uv run python main.py --image path/to/image.png

# Сравнение с PyTorch
uv run python comp.py

# Полная автоматическая проверка всех этапов (режим сдачи)
uv run python main.py --auto

# Запуск тестов (тихий режим)
uv run python test_laba2.py
```

## Пункты интерактивного меню

```text
1. Сгенерировать датасет (3 класса, размер 128x128)
2. Обучить перцептрон на текущем датасете (выбор размера батча)
3. Автоматическая проверка на тестовой выборке (метрики по классам)
4. Проверить случайный рисунок (ASCII-визуализация в консоли)
5. Распознать свою картинку по пути к файлу
6. Сохранить образец картинки на диск
7. Сравнение с PyTorch (lib.py / comp.py)
8. Уменьшить количество одного класса (дисбаланс: 100-300)
9. Переключить искажения (шум, повороты, битые пиксели, цвета)
10. Настройка распараллеливания на ядра CPU (выбор ядер + бенчмарк)
11. Полный авто-тест всех этапов задания (режим демонстрации)
12. Сохранить / Загрузить веса перцептрона (model.json)
0. Выход
```
